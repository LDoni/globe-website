# GLOBO visual assets

The active static wordmark is `globo-logo-static.png`; the matching original animated wordmark is `../videos/globo-logo-currents.webm`. The homepage uses `globo-sampling-network.png`, the owner-supplied 1743 × 902 illustration. These are distinct from quantitative NOAA layers and the editable station map.

The earlier transparent wordmark (`globo-logo-transparent.png`), 1600 × 491 overview (`globo-network-overview.jpg`) and Pacific illustration (`pacific-globo.svg`) are retained as legacy source assets; they are not used by the current homepage. Original supplied files remain preserved outside release inputs.

The first O has a small selective warm-colour enhancement and plays at 1.12×. Its unchanged source WebM remains the only video download. Inline SVG filter definitions affect warm pixels; the PNG-based second O keeps its independent 72-second orbit. Public browser preview artifacts provide same-frame before/after comparisons.
