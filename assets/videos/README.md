# GLOBO homepage animation

`globo-logo-currents.webm` is an unchanged copy of the owner-supplied GLOBO_logo_correnti_rosso_scuro_piu_visibili.webm.

Verified with actual Chromium playback: WebM/VP9, 2172 × 724, 18 seconds, 2,257,140 bytes and no audio tracks. The HTML uses muted autoplay, loop and playsinline without controls. Actual frame progression, native loop restart, reduced-motion continuous playback and a failed-media PNG fallback are checked in the browser suite. A touch/mobile emulation also verified automatic inline playback with no dropped frames in the short local sample; this is not a physical-device or Safari certification.

The paired owner-supplied static PNG is in assets/images/globo-logo-static.png. Neither image nor video was regenerated or altered. CSS blends their white background into the light page. The video is a project-brand illustration, not an observed environmental data product.

## Calmer second O

The first O continues to use the unchanged source video at its original speed. CSS clips out the video’s second O; that interior now uses the unchanged high-resolution static PNG, clipped into a fixed circular window and rotated smoothly once every 72 seconds. This avoids inheriting the source video’s 12-fps compression/flicker in the microorganisms, adds no media download, and leaves the outer mark stable. Both motions run continuously without controls, including under the requested reduced-motion behavior. Video conversion experiments are local-only and are not part of the published site.
