Quick guide for partners

Tickets and uploaded files are shared with all authorised GLOBO members.

  1. Sign in. Open Partner workspace, enter your authorised email and use the one-time code sent to your inbox.
  2. Edit the shared workbook. Choose Shared workbook or Open in Google Sheets. Google may require a separate sign-in and Editor permission.
  3. Read documents. In Documents & files, search by title or category and select a file to download.
  4. Create a request. Open Tickets → Create a ticket, enter a short title and description, then select Create ticket.
  5. Join the discussion. Open a ticket, write under Add a comment and select Post comment. Share its page link with other partners.
  6. Resolve and revisit. The author or a workspace coordinator can select Mark as resolved or Reopen ticket. Use the Resolved or All tickets filter to find the full discussion later.

Coordinator tools: Upload file accepts files up to 10 MB. Coordinators can import and publish sampling workbooks; partners select a published workbook in Sampling overview to view station sample/DNA counts.

Use Refresh tickets or Refresh discussion for recent changes. Updates may take a short time to appear in another session.
